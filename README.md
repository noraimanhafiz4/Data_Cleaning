# Data_Cleaning
A collection of reusable SQL scripts for data cleaning, pre-processing, and quality assurance. Designed to handle common data issues such as nulls, duplicates, and inconsistent formatting.

# 🧼 SQL Data Cleaning Toolbox

## 📌 Project Overview
Data cleaning often takes up 80% of an analyst's time. This repository serves as a centralized library of **reusable SQL queries** designed to handle common data quality issues. These scripts are built to be modular, allowing for quick deployment across different datasets to ensure data is "analysis-ready."

## 🛠️ Key SQL Techniques Used
* **Common Table Expressions (CTEs):** To create clean, readable multi-step transformations.
* **Window Functions:** For advanced deduplication and ranking.
* **String Manipulation:** Using `TRIM`, `REPLACE`, and `SUBSTRING` for text normalization.
* **Regular Expressions (Regex):** For complex pattern matching in unstructured strings.

## 💡 Why This Matters
In industries, data integrity is non-negotiable. This toolbox ensures that the underlying data for any dashboard or model is accurate, consistent, and reliable.
